6. Git 기초 명령어 7종(init, add, commit, push, pull, checkout, clone) 사용 증빙 요약
------------------------------------------------------------------------
- [1] git init     : git init -b main (로컬 Git 저장소 초기화)
- [2] git add      : git add .gitignore README.md quiz.py default_data.py input_utils.py storage.py quiz_game.py main.py state.json
- [3] git commit   : 기능 단위 의미 있는 커밋 17회 수행 (Chore / Feat / Test / Docs / Merge)
- [4] git checkout : git checkout -b feature/quiz-play 및 git checkout main
- [5] git merge    : git merge --no-ff feature/quiz-play (병합 커밋 06b1c8c)
- [6] git push     : git push -u origin main 및 git push origin feature/quiz-play
- [7] git clone    : git clone https://github.com/fox9star/codyssey-mission2.git codyssey-mission2-clone
- [8] git pull     : git pull origin main (복제 저장소에서 푸시한 커밋을 원본 로컬 저장소로 Fast-forward 병합)
